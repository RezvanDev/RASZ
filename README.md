# 💎 Personal AI Finance Bot (Личный ИИ-Финансист в Узбекистане)

Интеллектуальный Telegram-бот для комплексного управления личными финансами, инвестициями, пассивным доходом, вкладами и рассрочками в **Узбекистане (валюта UZS / сум, USD $)** на стеке **Python 3.11+, aiogram 3.x, SQLAlchemy 2.0, SQLite (WAL) и LLM (Function Calling)**.

---

## 🌟 Возможности бота

1. **Учет трат и доходов под реалии Узбекистана:**
   - Понимает свободный текст и голос (Whisper) в сумах и долларах.
   - Поддержка карт и платежных систем: **Uzcard, Humo, Click, Payme, Uzum Bank**.
   - Примеры: *«Обед в чайхане 65 000 сум»*, *«Такси 22 000 с карты Uzcard»*, *«Зарплата 15 000 000 сум»*, *«Купил 500$ в Капиталбанке»*.

2. **Учет активов, вкладов и пассивного дохода:**
   - Высокие ставки по депозитам в Узбекистане (20–23% в сумах, 5–7% в валюте).
   - **Автоматический ежедневный расчет сложных процентов:** бот сам каждую ночь начисляет доход ($Доход = Баланс \times \frac{Ставка}{365}$) и присылает утренний отчет.
   - Пример: *«Открыл онлайн-вклад в Капиталбанке на 30 000 000 сум под 22% годовых»*.

3. **Кредитные карты и рассрочки (Uzum Nasiya, Payme Nasiya и др.):**
   - Учет кредитного лимита, задолженности и льготного периода.
   - Корректный учет погашения долга как перевода (без задвоения расходов).

4. **Аналитика, метрики капитала и графические отчеты:**
   - **Net Worth** (чистый капитал = активы минус долги).
   - **Savings Rate** (норма сбережений в %).
   - **Runway** (подушка безопасности в месяцах спокойной жизни).
   - Красивые круговые диаграммы структуры трат (Donut Charts через Matplotlib) за 7 дней, 30 дней или месяц.

5. **Финансовые цели и ИИ-советник:**
   - Постановка целей: *«Хочу накопить 25 000 000 сум на ноутбук к августу»* или *«3 000$ на отпуск»*.
   - Персональный советник по оптимизации бюджета с учетом узбекских реалий.

## 🚀 Быстрый запуск

### 1. Подготовка конфигурации

Скопируйте пример окружения:
```bash
cp .env.example .env
```

Заполните переменные в `.env`:
* **`BOT_TOKEN`**: токен вашего бота от [@BotFather](https://t.me/BotFather).
* **`ADMIN_IDS`**: ваш Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot)), чтобы посторонние не имели доступа к вашим финансам.
* **`LLM_API_KEY`**: ключ OpenAI API (или любого прокси/совместимого провайдера: OpenRouter, DeepSeek, Groq).
* **`LLM_BASE_URL`**: URL эндпоинта (по умолчанию `https://api.openai.com/v1`, для DeepSeek или OpenRouter можно указать их URL).
* **`LLM_MODEL`**: например `gpt-4o-mini` (быстрая, дешевая и точная) или `gpt-4o`.

---

### 2. Запуск через Docker (Рекомендуемый для сервера)

```bash
docker compose up -d --build
```

Посмотреть логи:
```bash
docker compose logs -f
```

Остановить контейнер:
```bash
docker compose down
```

> **Важно:** База данных SQLite сохраняется в папке `./data/finance.db` на хосте, поэтому при пересборке или перезапуске контейнера данные никогда не пропадут.

---

### 3. Локальный запуск без Docker

```bash
# Создать и активировать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt

# Запустить бота
python3 main.py
```
